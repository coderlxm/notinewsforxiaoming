# Steam 低价提醒：使用小抄

想等一款游戏便宜了再买？把它交给小助手盯着就行。

目前看的是 Steam 中国区价格，金额都按人民币填写。

## 添加一款游戏

先打开游戏的 Steam 商店页面，复制页面地址。

然后发送：

```text
/steam add 游戏页面地址 你想买的价格
```

比如，你想等《星露谷物语》降到 30 元：

```text
/steam add https://store.steampowered.com/app/413150/Stardew_Valley/ 30
```

小助手会马上告诉你游戏名称、现在多少钱，以及有没有达到你的目标价。

## 看看正在关注哪些游戏

发送：

```text
/steam list
```

每款游戏前面都有一个编号，同时会显示目标价、现在的价格和关注以来最低的价格。

## 修改目标价

先用 `/steam list` 找到游戏前面的编号，然后发送：

```text
/steam set 编号 新价格
```

比如，把 2 号游戏的目标价改成 25.50 元：

```text
/steam set 2 25.50
```

## 不想再关注了

发送：

```text
/steam remove 编号
```

比如：

```text
/steam remove 2
```

## 现在就看一次价格

不想等下一次自动查看，可以发送：

```text
/steam check
```

## 什么时候会提醒我

出现下面两种情况时，小助手会来喊你：

- 游戏第一次降到你的目标价。
- 已经达到目标价后，又变得更便宜了。

价格没变时不会反复打扰你，涨价时也不会提醒。

## 小提醒

- 请复制游戏本体的 Steam 商店页面地址。
- 豪华版、合集和“补齐收藏”这类价格暂时不看。
- 免费游戏、还没有标价的游戏，以及中国区买不到的游戏不能添加。
- 不记得怎么用了，直接发送 `/steam` 就能看到简单提示。
