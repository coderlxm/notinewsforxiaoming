# Web Message 最小验收用例

<!-- Date: 2026-08-01 -->

## 使用范围

本轮只验收横幅提示迁移为 Element Plus Message 后的可见行为。以下 5 个用例覆盖短消息、常驻错误、路由清理、投稿状态与上传反馈；无需逐页重复检查同一类提示。

开始前准备：使用可登录的“我的资产”会话；投稿用例需要一条可使用的投稿链接，以及一张任意小图片。

## 用例 1：普通短消息与全局主题

1. 打开“我的资产”中的“发布内容”。
2. 在“添加图片/视频”中选择一个不支持的文件类型。

预期：

- 视口顶部出现红色错误 Message，而不是编辑区内的横幅。
- Message 使用站点的纸张色、石榴红、圆角和阴影风格，右侧有关闭按钮。
- 手动关闭后立即消失；不关闭则约 3 秒后自动消失。
- 页面内不残留原错误横幅。

## 用例 2：投稿表单校验

1. 打开有效投稿链接。
2. 不填写必填内容，直接点击“送给小明”。

预期：

- 顶部出现一条合并后的错误 Message，说明缺少的内容。
- 表单区域不出现校验错误横幅。
- 填写必填内容后可继续投稿，不会保留之前的校验提示块。

## 用例 3：终态错误会常驻且离开页面后清理

1. 在已登录状态下，打开一个不存在的文章编辑地址，例如将 `/me/articles/<真实文章 ID>/edit` 中的 ID 改成不存在的数字。
2. 等待读取结束。
3. 不关闭 Message，直接点击“返回我的资产”。

预期：

- 打开失败时显示可关闭的常驻错误 Message；编辑区不显示旧横幅。
- Message 在停留该页面期间不会自动消失。
- 返回“我的资产”后，该条常驻 Message 自动消失，不覆盖新页面。

## 用例 4：失效投稿链接

1. 打开一条缺少 `token` 或已失效的投稿链接。

预期：

- 顶部出现可关闭的常驻错误 Message，说明链接不可用。
- 不显示“暂时不能投稿”之类的页面内错误卡片。
- 投稿表单不会出现或可提交。

## 用例 5：投稿上传与处理过程

1. 打开有效投稿链接，填写称呼和正文，并选择准备好的小图片。
2. 点击“送给小明”，观察上传到完成的全过程。

预期：

- 上传开始后出现常驻信息 Message；提交按钮显示“正在上传 N%”，百分比随上传更新。
- 文件上传完成后，原上传 Message 关闭，并出现“服务器正在整理”的常驻信息 Message。
- 成功时处理中的 Message 关闭，显示现有投稿成功结果页。
- 若上传或整理失败，显示错误 Message，不显示旧的提交失败横幅。

## 通过标准

五个用例均满足预期，且删除确认、正常 Loading、投稿成功结果页仍保持原有交互，即可认为本轮 Message 迁移通过验收。
