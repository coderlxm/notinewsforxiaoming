## 自然语言提醒 — 基本输入

- [ ] 发送 `10 分钟后提醒我收衣服`，AI 解析成功并创建提醒
- [ ] 回复消息包含解析出的时间和内容
- [ ] 提醒到时正常触发
- [ ] 发送 `2 小时后提醒我看日志`，AI 解析成功并创建提醒
- [ ] 发送 `明天下午 3 点提醒我开会`，AI 解析成功并创建提醒（时间为次日 15:00 北京时间）

## 自然语言提醒 — 复杂输入

- [ ] 发送 `下周一早上 8 点提醒我提交周报`，AI 能正确计算日期和时间
- [ ] 发送 `每晚 10 点提醒我睡觉`（AI 应解析为今天的 22:00 或合理的未来时间）
- [ ] 发送 `2026年5月20日下午2点半提醒我老婆生快`，AI 能正确解析

## AI 输出校验 — 不合法不入库

- [ ] 发送非提醒内容（如闲聊），AI 不应创建提醒
  - 如果 AI 返回的 `trigger_at` 在过去，bot 回复"提醒时间必须在未来"，不创建记录
  - 如果 AI 返回的 JSON 不合法，bot 回复"没有识别到有效提醒时间"，不创建记录
  - 如果 AI 返回的 `intent` 不是 `create_reminder`，bot 回复"没有识别到有效提醒时间"
- [ ] 校验失败后数据库中无新增记录
- [ ] 校验失败不引发进程崩溃

## AI 配置缺失

- [ ] 临时清空 `.env` 中的 `DEEPSEEK_API_KEY`，发送自然语言消息
- [ ] bot 回复"AI 解析未配置，请使用 /remind 命令格式创建提醒。"
- [ ] 恢复 `DEEPSEEK_API_KEY` 后自然语言解析恢复正常

## 命令与自然语言共存

- [ ] `/remind 10m 收衣服` 仍走确定性解析，不走 AI
- [ ] 自然语言输入与 `/remind` 命令互不干扰
- [ ] 同一时间两种方式创建的提醒都能正常触发

## 不引入闲聊主路径

- [ ] bot 不会记忆上下文（每条消息独立解析）
- [ ] 无对话历史、无状态追踪
- [ ] 无 `/chat`、`/talk` 等闲聊命令
- [ ] 非提醒输入的回复始终是错误提示，不是闲聊回应
