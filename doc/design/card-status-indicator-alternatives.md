# 卡片状态角标替代方案

日期：2026-08-10

## 背景

卡片需要在右上角表达三种状态：置顶、加密和已解密。此前采用统一的三角折纸角标，整体方向和视觉效果得到认可，但深色折角直接覆盖浅色图片时，斜边会出现可见的底图混色毛边。

继续更换三角形的绘制 API 不能稳定解决该问题，因此后续方案需要保留状态识别价值，同时避免让大面积高反差色块通过长边直接覆盖任意图片。

## 设计原则

- 三种状态继续使用同一套图标，保证识别一致。
- 角标仍位于卡片右上角，不进入正文和时间信息区。
- 不再要求所有内容类型使用同一种角标底座。
- 已知背景使用模板化装饰，未知背景使用轻量图标。
- 不使用阴影、模糊、混合模式或大面积半透明色块遮盖问题。
- 不改变卡片原有圆角和媒体渲染路径。

## 推荐方案：统一图标，按内容载体自适应

### 纯文字画报

继续使用折纸角标。

纯文字画报的背景、模板颜色和布局由项目控制。每套模板可以为折角提供确定的背景色、折角色和边缘色，过渡不会面对不可预测的照片像素。

- 折角保持紧贴右上角。
- 颜色继承七套画报模板。
- 单状态显示一个图标，双状态在同一折角内并排。
- 加密预告画报使用同样方式。

### 图片、视频和带封面文章

不再使用带底色的三角折角，改为直接放置小型双色状态图标。

图标自身由两层矢量组成：

- 内层是中性白图标。
- 外层是约 1.5px 的深色轮廓。

深色轮廓属于图标本身，不是卡片边缘阴影。它只包围旗标、锁或开锁图形，不形成长斜边，也不会在图片上产生贯穿式白边。

- 图标紧贴右上安全区，但不使用独立色块。
- 单状态占用约 20px，双状态横向排列。
- 不使用圆形或方形背景，避免重新形成悬浮徽章。
- 视频与图片使用同一规则。

### 无封面文章和无媒体普通卡片

使用与纯文字画报一致的贴角装饰，但颜色采用项目强调色体系，而不是媒体图标方案。

这些卡片背景由项目控制，不存在任意图片颜色，因此可以安全使用有底色的角标。

## 为什么推荐混合方案

状态语义的一致性来自图标、位置和交互含义，不要求承载图标的底座完全相同。

纯文字画报需要装饰性，折纸可以强化模板风格；图片和视频本身已经是视觉主体，再覆盖大面积折角反而会抢夺画面。直接使用双色图标既保留状态识别，也更接近图片水印和媒体状态标识的常见做法。

该方案绕开的不是所有抗锯齿，而是此前最显眼的问题来源：一条长距离、高反差的折角边缘直接横跨图片。

## 其他可选方案

### 全部使用图标直贴

所有卡片都只显示双色图标，不再使用任何折角底座。

优点是实现最统一、稳定，缺点是失去已经得到认可的画报折纸效果，不推荐作为首选。

### 状态进入卡片元信息区

把状态图标放在时间或操作菜单旁边。

优点是没有媒体覆盖问题，缺点是状态不够醒目，而且会重新挤压移动端管理信息，不符合本次右上角标的目标。

### 为媒体预合成位图角标

为不同设备像素比准备无半透明边缘的固定 PNG 角标。

它可以减少浏览器实时绘制的不确定性，但需要维护多套颜色、尺寸和像素比资源；页面缩放后仍可能重新采样。收益不足以覆盖维护成本，不推荐。

### Canvas 同层绘制

将图片和角标绘制为同一 Canvas。

静态图片可以实现，但视频、多图、响应式尺寸、渐进加载和原生媒体交互都需要重做。对于状态标识需求属于明显过度设计，不采用。

## 状态组合规则

- 仅置顶：旗标图标。
- 加密且未解锁：锁图标。
- 加密且已解锁：开锁图标。
- 置顶并加密：旗标在左，锁或开锁在右。
- 公开、私有且未置顶：不显示角标。

## 实现范围

需要新增一个只负责状态图标组合的组件，并分别接入：

- 普通记录卡片。
- 文章卡片。
- 加密预告卡片。

纯文字画报复用模板解析结果决定折角配色；媒体卡片使用无底座双色图标。详情页不显示角标，继续使用现有状态信息。

不需要修改服务端、数据结构、接口或权限逻辑。

## 验收重点

- 图片和视频上不再出现大面积三角色块及长斜边。
- 双色图标在明暗图片上均可识别，但不能呈现为悬浮按钮。
- 七套画报的折角颜色与各自模板协调。
- 双状态不会压住卡片正文、日期或管理菜单。
- 卡片圆角、瀑布流高度和移动端信息布局保持不变。
