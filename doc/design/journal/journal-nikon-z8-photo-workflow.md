# Nikon Z8 到 Journal 的摄影发布链路备忘

## 推荐路径

分两个阶段推进：

1. 先直接使用 `Z8 → SnapBridge → Telegram bot → Journal`。拍摄 RAW + JPEG，只把满意的 JPEG 通过 SnapBridge 下载并分享给 bot，配一句文字即可发布，不需要开发新功能。
2. 确认使用频率和实际习惯后，再实现 `Z8 → SFTP → Journal 摄影收件箱`。Z8 回放时手动标记满意照片上传，Journal 默认将其保存为私有草稿，再通过手机补充文字并决定公开或保留私有。

## 后续实现边界

- 不自动上传所有照片，避免连拍、试拍和废片进入 Journal。
- 相机只上传 JPEG；RAW 保留在存储卡或电脑中归档。
- 摄影收件箱读取拍摄时间、镜头、焦距、光圈、快门、ISO 等 EXIF。
- 任何相机直传内容默认私有，必须经过人工确认才能公开。

理想的最终操作是：拍照 → 相机回放标记上传 → 手机打开 Journal 补一句话并发布。
