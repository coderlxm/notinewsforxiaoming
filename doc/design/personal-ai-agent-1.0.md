# 个人 AI Agent 1.0 产品规划与设计说明 (PRD)

## 1. 产品背景与定位

### 1.1 背景
随着站点生活记录、文章阅读、兴趣爱好及照片墙等模块的逐步完善，站内已积累了丰富的个人数据与上下文。为了将零散的数据与日常管理转化为主动的智能体验，需要在站内引入专属的**个人 AI Agent**。

### 1.2 产品定位
- **定位**：站长（Xiaoming）的专属数字助手与智能副驾驶（Personal Co-pilot）。
- **原则**：单用户工具，极简直观，聚焦真实使用场景，主路径最短，避免复杂的多用户、多租户或企业级冗余架构。

---

## 2. 导航入口与视觉设计（重点）

### 2.1 入口位置与排布
- **位置**：侧边栏主导航区，紧跟在「照片墙」下方。
- **层级关系**：
  1. 生活
  2. 文章
  3. 兴趣
  4. 照片墙
  5. **AI**（新增）

### 2.2 图标与视觉表现
- **图标风格**：
  - 采用当前流行的类 Gemini 风格多角星 / 璀璨星芒（Sparkle / Gem Star）矢量造型。
  - 采用彩色多色渐变（如靛蓝、紫罗兰、浅粉与天青色的平滑流光渐变 `linear-gradient(135deg, #4285F4, #9B72CB, #D96570)`）。
  - 醒目度高于常规单色图标，第一视觉直观传达“AI 智能应用”属性。
- **状态交互**：
  - **默认态（未激活）**：彩色渐变图标保持一定明度，配合灰白文字；Hover 时图标呈现微弱外发光或小幅度渐变流动。
  - **激活态（当前页面）**：延续站内导航激活样式（左侧指示条与背景微亮），图标保持全彩流光高亮。

---

## 3. 1.0 核心功能规划 (MVP)

1.0 版本核心聚焦于“**极简对话交互**”与“**站内数据上下文感知**”，不做复杂 Agent 工作流引擎，确保开箱即用、响应流畅。

### 3.1 极简对话与交互面板
- **流式对话输出（Streaming Response）**：支持打字机式平滑流式渲染（SSE），降低感知延迟。
- **Markdown & 富文本渲染**：支持代码高亮、表格、列表及链接排版。
- **快捷 Prompt / 灵感卡片**：
  - 空白会话页预置快捷气泡（如：“总结最近一周的生活动态”、“梳理近期文章灵感”、“帮我规划今日事项”），一键填入并触发。
- **会话管理**：
  - 支持创建新对话、查看近期历史会话、清除历史。
  - 状态轻量保存在本地或后端存储，刷新页面不丢失当前上下文。

### 3.2 站点上下文连接（Context-Awareness）
- **数据查询辅助**：AI 具备对站内生活日志、文章摘要、照片足迹与 Telegram 提醒的基础检索/关联能力。
- **辅助生成与沉淀**：对话产出的高质量内容（如日记草稿、灵感备忘）可一键快速复制或同步至相应模块。

## 4. 界面与交互布局草案

页面采用“框架常驻 + 左右分栏 / 单主栏”布局：

```text
+------------------+-------------------------------------------------------------+
| 侧边栏导航       | AI Agent 主工作区                                           |
|                  |                                                             |
| - 生活           | [ 历史会话列表 / 抽屉 (可选折叠) ]                          |
| - 文章           |                                                             |
| - 兴趣           | +---------------------------------------------------------+ |
| - 照片墙         | | 对话消息流展示区                                        | |
| - [✦ AI] (彩色)  | | - 用户提问                                              | |
|                  | | - AI 流式回复 (含代码/Markdown/快捷操作)                | |
|                  | +---------------------------------------------------------+ |
|                  | | [快捷 Prompt 推荐标签卡]                                | |
|                  | | [输入框 (支持快捷键发送、多行换行)   [  发送  ]]        | |
|                  | +---------------------------------------------------------+ |
+------------------+-------------------------------------------------------------+
```

---

## 5. 交互与体验要求

1. **框架常驻与即时响应**：切换至 AI 页面时，导航框架无跳变，无整页白屏重载。
2. **轻量与聚焦**：不堆叠企业级审批流、多模型复杂路由，聚焦个人常用主力模型。
3. **响应式适配**：移动端下侧边栏收起为汉堡菜单，AI 底部输入栏贴合移动端软键盘交互。

---

## 6. 后续演进规划 (2.0+)
- **2.0 阶段**：深度联动 Telegram Bot（双端会话互通与推送）、自动化周期性报告（每周生活摘要自动生成）。
- **3.0 阶段**：个人私有知识库沉淀与主动触发提醒。
