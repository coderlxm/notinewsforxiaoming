# 移动端简历视觉去重与一体化卡片重构建议 (Mobile Resume Redundancy Elimination)

## 1. 现状痛点定位：移动端视觉“三重重复”问题诊断

通过手机端实际截屏分析，当前页面在 1 屏之内存在严重的**多组件信息与动作冗余**：

```text
【痛点 1：双重头像与人名】
AppHeader (全局顶栏)  -> 头像 + 小明同学 + "茕茕白兔，东走西顾..."
ResumeHero (中部名片) -> 头像 + 小明同学 + "茕茕白兔，东走西顾..." (100% 冗余)

【痛点 2：双重文件名与页数】
ResumeHero 底部      -> "PDF (3P) · 更新于 2026/08/16 · 李小明-Web前端工程师-5年-本科.pdf"
PdfResumeViewer 卡片 -> "PDF 专属文档 / 李小明-Web前端工程师-5年-本科.pdf / 共 3 页" (100% 冗余)

【痛点 3：双重核心操作按钮】
PdfResumeViewer 卡片 -> [全屏原生阅读]、[下载 PDF 简历原件]
底部 ResumeFloatingDock -> [原版]、[下载原件]、[复制地址]、[关于我] (80% 冗余)
```

---

## 2. 改进方案：移动端“一体化个人档案卡” (Unified Mobile Portfolio Card)

### 2.1 核心重构原则
1. **依附全局顶栏，彻底移除重复的 Hero 头像与人名**：
   - 移动端顶部已有全局 `AppHeader` 呈现头像、姓名与座右铭，下方不再重复绘制大号头像与座右铭。
2. **三合一卡片设计 (Unified Mobile Card)**：
   - 将“联系方式”、“文档信息”与“操作按钮”整合为一张**高度集约、质感极高的移动端专属档案卡**。
3. **移动端隐藏底部悬浮 Dock**：
   - 所有操作（全屏查看、下载原件、复制分享、返回关于我）在一体化卡片内原生闭环，彻底移除底部悬浮 Dock，让手机全屏视野 100% 干净、通透。

## 3. 预期美学与体验收益

1. **信息密度恰到好处**：从原本的“顶栏 + 名片 + 文档卡 + 悬浮底栏” 4 层堆叠，收敛为“顶栏 + 1 张精炼档案卡”，首屏一目了然。
2. **0 视觉内耗**：每个头像、人名、文件名和按钮在手机屏幕上只出现 1 次。
3. **操作极致高效**：全屏查看、下载、复制、返回所有行动点汇聚在卡片内，符合移动端触控习惯。
