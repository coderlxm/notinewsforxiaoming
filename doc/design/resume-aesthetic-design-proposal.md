# 个人简历对外呈现与美学重构方案 (Resume Aesthetic Redesign)

## 1. 与本项目视觉风格的深度契合性审查 (System Consistency Review)

本设计方案严格基于 NotiNews / Journal 站点的“文人手记 / 现代杂志志书 (Modern Curated & Editorial)”视觉设计规范，确保新呈现层与全站现有页面（如 `/about`、`/` 志书瀑布流、详情页）在气质、质感、色彩和交互上高度统一，绝不产生割裂或突兀感。

### 1.1 核心设计资产与 Token 的 100% 沿用
- **色彩体系 (Palettes)**：
  - 浅色模式：暖米纸质感 `--paper: #f7f7f5`、卡片底色 `--card: #ffffff`、正文字色 `--ink: #20201e`、辅助字色 `--graphite: #72716c`、核心点睛色 `--pomegranate: #c43b46`（深石榴红）、边框色 `--border-subtle: #ecece8` 与 `--border-strong: #d3d3ce`。
  - 深色模式：黑曜岩底色 `--paper: #1d1d1b`、深石墨卡片 `--card: #272725`、文字 `--ink: #f2f1ed`、暗夜石榴红点睛 `--accent-strong: #f06b75`。
- **排版字体体系 (Typography)**：
  - 标题与名字：沿用站内宋体 `--font-serif: "Noto Serif SC", "Songti SC", STSong, serif`，保持儒雅、严谨的文人气质。
  - 正文与说明：沿用标准无衬线体 `--font-sans: Inter, ...`。
  - 时间与元数据：沿用站内紧凑等宽体 `--font-condensed: "Arial Narrow", "Roboto Condensed", Arial, sans-serif`。
- **空间与圆角 (Spacing & Radius)**：
  - 容器宽度统一为 `width: min(calc(100% - (var(--page-gutter) * 2)), 960px)`，与 `AboutView.vue` 和全局阅读流完全对齐。
  - 圆角统一遵循 `--radius-card: 12px` 与 `--radius-media: 10px`。
  - 阴影统一遵循站内微质感漫反射公式：`box-shadow: 0 10px 24px color-mix(in srgb, var(--ink) 12%, transparent)`。

### 1.2 现有业务组件与数据的自然延伸
- **联系方式**：直接复用 `AboutContactIcon.vue` 的精致 SVG 矢量图标和 `siteProfile.contactItems` 数据源，保证 `/about` 与 `/resume` 的联系渠道（GitHub, Email, Telegram, 微信等）视觉与数据完全同源。
- **全局外壳**：页面顶部继续承接全局 `AppHeader`，简历视图作为专属画卷在下方舒展展开，层级自然顺畅。

## 2. 对既有重构建议（GPT 建议）的客观审视

既有文档 `doc/design/resume-presentation-redesign.md` 准确指出了当前系统的核心产品缺陷，但在美学实现与方案路线上存在明显局限：

### 2.1 准确且值得采纳的判断
- **认知偏差定位准确**：当前实现把“文件预览”这一后台/CMS 基础功能，误当成了“公开个人形象门面”。
- **PDF 原生 iframe 的硬伤分析透彻**：3 层嵌套（深色站点 -> 深色浏览器阅读器 -> 白色 PDF）、双套工具栏并存、移动端体验不可控，确实不适合作为对外简历页面。
- **Markdown 文章化排版的平庸感**：通用博客文章的单列 800px 居中排版、松散行高与默认标题，完全失去了简历应有的信息密度与职业张力。

### 2.2 既有建议的局限与偏差
- **陷入规则与技术争议，忽略了“美学第一优先级”**：过度纠结于 RAF 与 PDF.js 的技术冲突，未能在视觉层面上给出令人惊艳的方案。简历作为个人门面，首要目标是给招聘方/合作方带来强烈的专业感、设计感与信任感。
- **Markdown 方案将排版问题误诊为“数据校验问题”**：提议建立严格的 Markdown AST 校验与报错机制，这把轻量灵活的内容输入复杂化了。高质量简历页面的关键在于**基于现代 CSS Grid、微排版（Micro-Typography）和卡片/时间线层级的高级样式系统**，而非强制限制作者的 Markdown 语法。
- **缺乏“门面感”的核心视觉组件**：遗漏了个人身份区（Identity Hero）、悬浮操作岛（Floating Action Dock）、桌面纸张光影（Paper Elevation）等能够瞬间拉开视觉档次的设计元素。

## 3. 具体模块视觉设计方案（融入本站美学）

### 3.1 统一页面外壳：身份名片区与悬浮操作岛 (Identity Hero & Floating Dock)

无论当前加载的是 PDF 还是 Markdown，访客进入页面首先看到统一的品牌化外壳：

1. **顶部个人身份名片 (Identity Hero)**：
   - **姓名与职位**：大号加粗姓名（`var(--font-serif)`） + 优雅的职位副标题（例如：`小明同学` · `全栈工程师 / Independent Developer`）。
   - **交互式联系药丸群 (Contact Pills)**：复用 `AboutContactIcon.vue` 的小巧 SVG 图标，结合圆角药丸胶囊（Pill Tags），鼠标悬浮带有精致的石榴红边框高亮（`border-left-color: var(--accent)`）。
   - **元数据信息**：更新时间与格式徽章以极简微字体呈现在右上角。
2. **悬浮式雅致操作岛 (Floating Action Dock)**：
   - 彻底移除正文上方传统的单调灰字工具栏。
   - 将“返回关于我”、“复制分享链接”、“下载原文件”、“缩放/页码”收纳为屏幕底部/边缘吸附的极简毛玻璃胶囊（使用站内 `--surface-card` 与细腻阴影）。
   - 保证访客在任何滚动深度下都能一键下载或分享，同时正文阅读区域保持 100% 纯净无干扰。

---

### 3.2 PDF 呈现模式：“桌面上的悬浮纸张” (The Curated Paper Sheet)

针对 PDF 格式的呈现重构：

1. **摆脱原生 iframe 灰黑框**：
   - 不再将整个原生浏览器 PDF Viewer 暴露给访客。
   - 将 PDF 渲染为单页或多页连续纵向排列的“悬浮纸张流”（Paper Stream）。
2. **纸张物理光影与排版**：
   - 纸张具有标准的 A4 黄金比例，居中陈列在站内温暖中性的 `--paper` 纸张背景上。
   - 纸张边缘带有柔和的物理阴影与 1px 极细边框（`border: 1px solid var(--border-subtle)`），模拟真实桌面上的精印纸张。
   - 多页 PDF 之间保留 24px 呼吸间隙，并在每页右下角带有优雅的浮动页码指示（如 `01 / 02`）。
3. **响应式与移动端适配**：
   - 桌面端：固定最大宽度居中展示，保证文字极其锐利清晰。
   - 移动端：自动适配屏幕宽度，支持平滑缩放，杜绝横向滚动条撕裂布局。

---

### 3.3 Markdown 呈现模式：“杂志级双列交互简历” (Editorial Magazine Resume)

针对 Markdown 格式的呈现重构：

1. **现代化非对称双列网格 (Asymmetric 2-Column Grid)**：
   - 放弃单一居中长文本，在桌面端自动启用双列杂志排版：
     - **左侧专栏（个人画像与技能矩阵，约占 32% 宽度）**：
       - 个人简介与核心优势卡片。
       - **技能矩阵**：分类呈现（如前端、后端、架构、工具），技能项自动渲染为精致标签胶囊（Skill Badges）。
       - 教育经历、资质证书、开源贡献。
     - **右侧主栏（经历与项目时间线，约占 68% 宽度）**：
       - **工作经历时间轴**：左侧带有细贯穿线与石榴红节点，公司名与职位层级分明，起止时间清晰右对齐。
       - **重点项目矩阵**：项目名称加粗，成果列以微卡片形式展示，技术栈标签以弱对比色附于项目底部。
2. **移动端自适应**：
   - 在平板和手机端，非对称双列自然降级为单列纵向流，左侧信息前置或折叠为紧凑卡片，无需依赖复杂 JS 重新排版。

---

### 3.4 访问口令页升级：“专属档案解密”仪式感 (Refined Access Gate)

针对口令保护状态（`protected`）的升级设计：

1. **6位分立验证码格子 (Split OTP Box)**：
   - 替换当前普通的单行 input 输入框。
   - 采用 6 个独立方形数字格，当前激活格带有石榴红呼吸光环，输入数字后光标自动步进，输满 6 位自动触发解密。
2. **私密档案氛围感**：
   - 保留现有的典雅锁头印章徽标与石榴红微光背景，与全站其他受保护条目的解锁风格呼应。
   - 文本提示强化“受保护的个人专属简历”概念，提升求职/合作方的专属仪式感。

## 4. 实施落地与代码约束平衡建议

为了在满足美学第一优先级的同时，严格遵守项目的代码原则（保持实现直接、不引入冗余抽象、无 RAF 禁令冲突）：

1. **外壳层复用 (Shell & Layout)**：
   - 新建 `ResumeShell.vue`，集中管理 Identity Hero、背景舞台和 Floating Dock，彻底拆除原页面内外的两套重复工具栏。
2. **Markdown 样式层增强 (CSS-Only Modernization)**：
   - 无需编写复杂 AST 转换器，通过针对性的 CSS 类与现代选择器（CSS Grid、Flex、`:has()`、伪元素时间线），即可将标准 Markdown 渲染出的 HTML（`<h1>`~`<h3>`、`<ul>`、`<p>`）直接渲染出杂志级双列与时间轴效果。
3. **PDF 呈现路线选择**：
   - 优先采用无缝的高清 Canvas 页面流或轻量纯净 PDF 渲染器，只展示纸张画面本身，所有缩放、翻页、下载操作均由本站统一的 Floating Dock 接管。
