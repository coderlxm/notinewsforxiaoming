# 个人简历 Kindle 风格纸张翻页动效方案设计 (Resume Kindle-style Page Flip)

## 1. 需求背景与目标

当前个人简历在桌面端展示 PDF 预览图时，采用的是单页即时替换模式，切换页码时没有任何物理过渡，缺乏真实纸张阅读的质感与沉浸感。

本方案旨在为个人简历 PDF 阅读器引入**类似于 Kindle 电子书 / 拟真纸质书的丝滑 3D 纸张翻页动画**，使翻页过程呈现自然的卷折立体感、光影明暗流动与纸张层次吸附感，同时保持极高的性能与代码纯粹性。

---

## 2. 核心设计原则

1. **真实物理质感 (Realistic Physics & Lighting)**
   - 翻页具有 3D 透视深度与纸张翻转弧度，而非生硬的平面滑动。
   - 翻折过程中动态叠加纸张明暗光影（高光与背光暗部阴影）及底层纸张的投射阴影。
   - 纸张边缘带有微立体层叠阴影，模拟纸张叠放的真实厚度感。
2. **丝滑克制 (Smooth & Restrained)**
   - 动画时长控制在 480ms ~ 540ms，采用符合物理运动的贝塞尔曲线（`cubic-bezier(0.32, 0.94, 0.60, 1)`），快速翻动不拖沓。
3. **零非标 API 与纯 CSS 3D 硬件加速**
   - 严禁使用 `requestAnimationFrame`，采用纯 CSS 3D Transforms (`perspective`, `rotateY`, `transform-origin`) 与 GPU 硬件加速，确保在 60fps/120fps 下丝滑不掉帧。
4. **暗色与亮色模式深度自适应**
   - 浅色模式下展现温润纸张光影；深色模式下自动切换为深色光影遮罩与纸张质感。
5. **极简健壮的状态管理**
   - 翻页状态原子化管理（`fromPage`, `toPage`, `direction: 'next' | 'prev'`, `isFlipping`），翻页完成后平滑归位，防止连击错乱。

### 3.2 翻页动画分解

#### 1. 向后翻页 (Next: Page N → N+1)
- **初始态**：
  - 底层展示 Page N+1，上面覆盖一层由深至浅的 `under-shadow`；
  - 翻动层（Flipper）处于 `rotateY(0deg)`，正面为 Page N；
- **动画过程**：
  - 翻动层绕左边缘旋转至 `rotateY(-180deg)`；
  - 正面阴影由透明渐变至半暗，背面遮罩在转过 90° 时显现并随着贴平淡出；
  - 底层 `under-shadow` 随着纸张掀起逐渐淡出为 0；
- **结束收敛**：
  - 动画结束后 `currentPage` 置为 N+1，销毁动画层，回到静止单张模式。

#### 2. 向前翻页 (Prev: Page N → N-1)
- **初始态**：
  - 底层展示 Page N；
  - 翻动层初始置于左侧 `rotateY(-180deg)`，正面为 Page N-1；
  - 底层覆盖 `under-shadow`，翻动层背面朝上；
- **动画过程**：
  - 翻动层从 `rotateY(-180deg)` 平滑翻转合盖至 `rotateY(0deg)`；
  - 翻动层阴影与底层阴影平稳收敛；
- **结束收敛**：
  - 动画结束后 `currentPage` 置为 N-1，销毁动画层，回到静止单张模式。
