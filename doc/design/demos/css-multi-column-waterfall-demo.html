真正决定布局的 CSS

.waterfall {
  column-count: 4;
  column-gap: 16px;
}

.card {
  break-inside: avoid;
  margin-bottom: 16px;
}

@media (max-width: 620px) {
  .waterfall { column-count: 2; }
}

break-inside: avoid 保证卡片不会被截成上下两段。浏览器负责分列和平衡列高，不需要 JavaScript 计算位置。
