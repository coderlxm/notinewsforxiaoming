# 循环提醒时间异常（简要求助背景）

## 现象

循环提醒创建后，`下次` 时间有时不符合直觉：

- 在当天目标时间之前创建，`下次` 仍显示为明天。
- 曾出现规则时间与展示时间不一致（例如规则是 `22:30`，展示成其他时刻）。

## 最小示例

输入：`每晚11点10分提醒我做俯卧撑`

预期：如果当前时间还没到 23:10，`下次` 应该是今天 23:10。  
实际：有时显示为次日 23:10。

## 求助问题

希望得到一个稳定、可维护的实现建议，确保：

1. “今天未到点”时优先命中今天；
2. `下次` 展示与实际触发一致；
3. 不依赖宿主机时区差异导致行为变化。
