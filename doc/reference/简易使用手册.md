# Journal 简易使用手册

## 1. 地址与密码

- 公开信息流：`https://feeds.xmcloud.buzz/`
- 私有资产与管理：`https://feeds.xmcloud.buzz/me`
- RSS：`https://feeds.xmcloud.buzz/rss.xml`
- JSON Feed：`https://feeds.xmcloud.buzz/feed.json`


密码按你的要求只保留在本地交付副本中，不提交到 GitHub。你确认登录成功后可以删除本节密码行。

## 2. 在 Telegram 中记录

### 直接记录文字

- `/note 今天散步很舒服 #生活`：保存为私有笔记。
- `/post 今天散步很舒服 #生活`：保存为公开动态。

`#标签` 会自动提取，之后可以在网站中点击或筛选。

### 保存既有消息

对任意既有消息使用 Telegram 的“回复”，然后发送 `/note` 或 `/post`。保存目标是被回复的原消息，不是命令消息。

### 先发命令、再发内容

单独发送 `/note` 或 `/post`，bot 会提示发送下一条内容。下一条支持文字、媒体和结构化消息；发送 `/cancel` 可取消本次等待。

### 记录图片、视频、语音和文件

可以把 `/note` 或 `/post` 写在媒体 caption 开头，也可以先进入一次性等待再发送媒体。

初版支持：

- 图片、照片相册
- 视频、圆形视频、动画、视频相册
- 语音、音频
- 普通文件
- 静态或动态贴纸
- 位置、地点、联系人、投票、骰子、游戏、story、checklist、paid media 等 Telegram 原始结构化消息

照片/视频相册在网页中合并为一条记录。Telegram 云端 Bot API 的单文件下载上限为 20 MB；超限会直接显示失败，不会创建声称附件完整的成功记录。

## 3. 保存后的操作

bot 会编辑原提示消息显示保存结果，并提供：

- `设为公开` 或 `转为私有`：立即切换整条记录的可见性。
- `打开网站`：公开记录打开永久详情，私有记录打开 `/me`。

公开记录会出现在首页、公开详情、RSS 和 JSON Feed。私有记录只在管理员登录后的 `/me` 中出现，私有附件也要求同一登录状态。

## 4. 私有资产管理

进入 `/me`，输入本手册中的管理员密码。登录后可以：

- 按公开/私有、关键词、标签、内容类型和日期范围筛选。
- 编辑正文，正文中的标签会随编辑结果重新提取。
- 置顶或取消置顶。
- 在公开和私有之间切换。
- 查看往年今日。
- 加载更早记录。

管理员登录使用签名 HttpOnly Cookie；退出登录后私有列表与私有媒体不再可访问。

## 5. 可见性原则

- `/note` 默认私有，适合随意记录和个人资产。
- `/post` 默认公开，适合让他人从信息流或订阅源观看。
- 每条记录都可在 Telegram 保存结果或 `/me` 中随时切换。
- 一条记录转为私有后，公开详情、公开媒体和订阅源会立即不再提供它。

## 7. 最短首用流程

1. 在 Telegram 发送 `/note 我的第一条私有日记 #开始`。
2. 打开 `https://feeds.xmcloud.buzz/me`，使用本手册密码登录并查看记录。
3. 在 Telegram 发送 `/post 我的第一条公开动态 #开始`。
4. 打开公开首页查看，再用 bot 结果按钮把它转为私有，确认首页不再显示。
