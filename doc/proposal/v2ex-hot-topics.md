# 技术方案建议书：V2EX 今日热议脱水总结

## 1. 目标
通过自动化工具获取 V2EX 站内的当日最热帖子，利用 DeepSeek AI 进行内容聚类、摘要和“看点”提炼，为用户提供一份高浓度的社区动态简报。

## 2. 数据获取方案 (Fetcher)
*   **接口选择**：
    *   **官方 API**：`https://www.v2ex.com/api/topics/hot.json` (最推荐，返回纯净 JSON)。
    *   **备选 RSSHub**：`https://rsshub.app/v2ex/topics/hot` (如果官方 API 有频率限制)。
*   **抓取策略**：
    *   抓取前 10-15 条热帖的标题、所属节点、内容大意及链接。
    *   为了更深度的总结，可以尝试抓取前 3 条最热帖子的部分高赞回复（可选，取决于 AI 的上下文容量）。

## 3. AI 总结逻辑 (AI Service)
*   **Prompt 设计**：
    *   **角色定义**：一位深谙 V2EX 社区文化、既能硬核聊技术又能深度剖析情感的人间清醒观察者。
    *   **任务**：将热帖分类，**特别加强两性与情感类话题的权重**。
    *   **权重逻辑**：
        *   对涉及 `all4all` (缘分天空)、`love` (酷爱)、`marriage` (结婚) 等情感类节点的帖子，给予**特写镜头**。
        *   这类帖子要求 AI 解析出：原帖的纠结点、评论区的核心矛盾（如：劝分还是劝和）、最有代表性的三观碰撞。
    *   **看点提炼**：不仅总结帖子说了什么，还要总结**大家在争论什么**或者**有什么神评论**。
    *   **输出控制**：普通技术贴保持精炼，**情感生活贴允许详细拆解**，使用 HTML 格式。

## 4. 消息排版方案 (Formatter)
*   **视觉结构**：
    *   🚀 **V2EX 社区热点脱水** (日期)
    *   ---
    *   📂 **分类总结** (如：[程序员] 某大厂又... | [奇思妙想] 如果...)
    *   🔥 **核心看点** (AI 提炼的精华讨论)
    *   🔗 **直达链接** (前 5 个最热贴的跳转)

## 5. 推送策略建议 (Scheduler)
建议放在 **北京时间 21:00 - 22:00**（睡前读物模式）：
*   此时全天的热帖已经发酵完成，总结的含金量最高。
*   可以作为你一天结束后的“社区动态概览”。

## 6. 实现步骤建议
1.  **新建 `src/fetchers/v2ex.ts`**：封装对 V2EX API 的请求。
2.  **更新 `src/ai/deepseek.ts`**：增加 `summarizeV2exWithAI` 函数。
3.  **更新 `src/formatters/index.ts`**：增加 `formatV2exMessage` 格式化器。
4.  **更新 `src/index.ts`**：在晚间时段增加该逻辑。

## 7. 风险点
*   **API 频率限制**：V2EX 的 API 有较为严格的 Rate Limit，需要增加简单的缓存或避免过于频繁的调试请求。
*   **内容偏好**：AI 需要被教育如何过滤掉过于琐碎的“水贴”。
