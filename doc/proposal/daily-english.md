# 产品需求文档 (PRD) - 每日英语碎片化学习模块

## 1. 项目背景
在日常推送中加入英语学习内容，利用海外高质量媒体资源（IGN, BBC, TechCrunch 等）作为素材，结合 DeepSeek AI 的教学能力，为用户提供每日 2 次、每次 5 分钟的轻量化英语学习体验。

## 2. 目标用户
*   **用户画像**：小明
*   **英语水平**：CET-6 级别，词汇量约 5000。
*   **核心痛点**：缺乏地道语境、长篇阅读难以坚持、词汇碎片化。

## 3. 功能需求
### 3.1 自动化素材抓取 (Fetcher)
*   **来源策略**：
    *   **游戏/娱乐**：IGN (已验证稳定性高)
    *   **科技**：TechCrunch, The Verge
    *   **综合/新闻**：BBC News, Reuters
    *   **体育**：ESPN
*   **抓取逻辑**：
    *   每日随机从不同类别的 RSS 源中抽取一条具有代表性的短文（或新闻摘要）。
    *   优先选择长度适中（100-300 词）的段落。

### 3.2 AI 智能教学 (AI Service)
*   **角色设定**：资深英语教学专家，擅长将复杂的新闻语言拆解为适合 CET-6 学习的干货。
*   **教学内容包含**：
    1.  **原文呈现**：精选出的地道段落。
    2.  **核心词汇解析**：从段落中挑选 3-5 个 CET-6 难度及以上的重点单词或短语，提供音标、中文义项及本句中的含义。
    3.  **难句拆解**：解析 1 个复杂的长难句结构（如从句、非谓语动词等）。
    4.  **内容归纳**：一句话概括这段内容在说什么（中英双语）。
    5.  **互动思考/短评**：用一句鼓励性的话语结尾。

### 3.3 定时推送策略 (Scheduler)
*   **推送频率**：每日 2 次。
*   **时间窗设定**（避开深夜与凌晨）：
    *   **第一推**：上午 10:30 - 11:30 之间（上午茶时间）。
    *   **第二推**：下午 16:00 - 17:30 之间（下班前摸鱼时间）。
*   **分发渠道**：Telegram Bot。

## 4. AI 提示词 (Prompt) 设计方案
```text
Role: 你是一位拥有 20 年经验的资深英语老师，擅长将原版新闻作为教材。
Target: 你的学生是 CET-6 水平（词汇量 5000），希望在 5 分钟内完成碎片化学习。
Input: 下面是一段来自 ${source} 的英语原文：
${content}

Task:
请按以下格式输出教学内容（Markdown）：
1. 📖 **今日原文 (Selection)**:
   > (显示原文段落)
2. 💡 **重点词汇 (Key Vocabulary)**:
   * (单词/短语) [音标] - (中文含义)
3. 🔍 **长难句拆解 (Sentence Analysis)**:
   * (提取句子) -> (结构解析)
4. 📝 **名师总结 (Summary)**:
   * (中英双语概括)
5. 🎓 **课后私语**:
   * (简短的励志话语或互动)
```

## 5. 稳定性保证
*   **Fallback 机制**：如果所有 RSS 源抓取失败，AI 将自动生成一条“今日励志名言”或“地道习惯用语讲解”作为替补推送。
*   **多源并发**：同时请求多个源，取响应最快的一个。

## 6. 后续扩展
*   **发音支持**：未来可接入 TTS (文本转语音) 生成音频。
*   **单词本同步**：点击单词可直接收藏到个人笔记。
