# 技术方案建议书：智能健身私教模块

## 1. 目标
为用户提供每周 3 次（周一、三、六）的个性化健身计划推送。利用 DeepSeek AI 作为私人教练，制定安全、适度、侧重减脂且器械要求低的训练方案。

## 2. 调度逻辑 (Scheduler)
由于需要区分“周几”，现有的调度逻辑需要升级。
*   **推送时间表**（北京时间）：
    *   **周一**：20:30 (下班后燃脂)
    *   **周三**：20:30 (周中体能维持)
    *   **周六**：14:00 (周末大循环)
*   **判定逻辑**：在 `src/index.ts` 中增加 `new Date().getDay()` 判定，只有在对应的日子和时间点才会触发。

## 3. AI 教练逻辑 (AI Service)
*   **角色设定**：一位极具亲和力、极其注重动作安全性的专业健身教练。
*   **Prompt 核心要求**：
    *   **安全性第一**：必须包含热身和拉伸环节，严禁推荐高风险动作。
    *   **减脂导向**：侧重高频率、适度负重的循环训练。
    *   **低门槛**：以哑铃（或水瓶）、弹力带、自重动作为主，或者是健身房最基础的固定器械。
    *   **结构化输出**：按“热身 -> 正式训练（动作+组数+休息时间） -> 拉伸”排列。

## 4. 消息排版方案 (Formatter)
使用 HTML 格式，配合 Emoji 增强趣味性：
*   🏋️‍♂️ **今日健身课表** (日期/星期)
*   🔥 **本课目标**：(如：全身燃脂 / 下肢塑形)
*   ---
*   🏃 **第一阶段：热身** (5-8分钟)
*   💪 **第二阶段：正式训练** (4-5个动作，简单易学)
*   🧘 **第三阶段：拉伸与恢复** (5分钟)
*   ---
*   📢 **教练寄语**：(AI 鼓励话语)

## 5. 我的额外建议 (Future Ideas)
1.  **动态循环**：周一、三、六的计划可以设定不同的主题（例如：周一上肢+有氧，周三下肢+核心，周六全身大循环），AI 会自动根据周期进行轮换。
2.  **补水/饮食提醒**：在推送中自动加入“练后 30 分钟记得补充优质蛋白质”或“练中注意少量多次补水”的小贴士。
3.  **打卡反馈**：消息下方可以预留一个链接或按钮，方便你点击记录“已完成”，后续甚至可以做成每周进度报告。
4.  **根据天气调整**：如果当天由于天气原因无法出门（如暴雨），AI 会自动切换为“纯居家自重方案”。
